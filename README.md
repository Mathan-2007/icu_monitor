# 🫀 AI-Driven ICU Patient Monitoring & Clinical Dashboard

Real-time ICU monitoring with AI risk scoring, alert prioritization, and clinical summaries.

## Stack
React + Tailwind   Node.js + Express | MongoDB | Socket.IO | Gemini API

## Roles
Admin / Doctor / Nurse (RBAC + audit logging)

## Run
cd server && npm i && npm run seed && npm run dev
cd client && npm i && npm run dev
